## Runtime impact and remaining risk

The application uses public hooks/configuration covered by the official v0.15 migration guide and Context7: `useChatRuntime`, `AssistantRuntimeProvider` with `AuiConfig`, `useAuiState`, and external-store runtime APIs. No mechanical API migration was needed.

- `/app/assistant.tsx` retains `useChatRuntime`, `isSendDisabled`, conditional automatic tool continuation, and model context registration. The welcome trigger still delegates sending to upstream policy; no `composer.canSend` visibility guard was added.
- `/app/opencode-session.tsx` retains external-store messages, host-controlled running state, cancellation, send-disable and approval callbacks. The candidate includes upstream external-store message/cancel/timestamp changes, so passing typechecks alone would not establish behavioral safety.
- `/app/opencode-native-session.tsx` retains `useOpenCodeRuntime`, saved native session/model/agent options, authenticated client and the app's recovery/permission guard. Core releases change thread-list hosting, title sequencing and cancellation paths even with an unchanged native adapter. Title restoration, independent permissions/cancel and reconnect must therefore receive real browser proof.
- Published core changelog highlights include the remote-thread-list store-client transition (`#9650`), optional `canResume` (`#9861`), external-store cancel handling (`#9509`), title sequencing (`#9551`, `#9556`, `#9864`) and composer events (`#9990`). Do not interpret these as fixes to the app's documented long-outage limitation.
- Existing app-owned and copied UI compile against the candidate in a new directory without TypeScript incremental state. The coordinator's checkout initially retained 16 approval-type diagnostics even after installing the candidate. Removing only the generated `.next/cache/.tsbuildinfo` and repeating `NEXT_TELEMETRY_DISABLED=1 bun run build` produced a passing production build. The earlier cached diagnostics are not evidence of an incompatibility in the current pins or candidate.
- Pi is absent and out of scope. The dependency agent launched no CLI, server or browser E2E. The coordinator subsequently passed real AI SDK, ACP and native opencode browser acceptance against the combined upgrade, including narrow layout and shell focus, approvals/cancellation, model/session ownership and reload/password re-entry. See the linked report for exact coverage and limits; long-outage recovery was not retested or claimed fixed.
